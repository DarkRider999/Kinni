# Pioneer DJ DDJ-FLX4 for DJ Nexus Pro
#
# MIDI numbers as documented by the Mixxx community mapping for this
# controller. Not yet checked on hardware by DJ Nexus. The controller sends
# different notes when SHIFT is held, so shifted functions are ordinary bindings.
# Pads: each pad mode sends its own notes, so hot cues, beat loops and the
# sampler all work in their mode. Beat Jump, Keyboard, Key Shift and Pad FX
# modes are not mapped yet.
# If the tempo fader runs the wrong way on your unit, delete "invert".
name: Pioneer DDJ-FLX4
device: DDJ-FLX4

# The FLX4 expects a host keep-alive (otherwise it drops back to its
# stand-alone light show), and the loop buttons are lit while a host is connected.
send every=200 F0 00 40 05 00 00 04 05 00 50 02 F7
send 90 10 7F
send 90 11 7F
send 90 4C 7F
send 90 4E 7F
send 91 10 7F
send 91 11 7F
send 91 4C 7F
send 91 4E 7F
